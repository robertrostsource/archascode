# Architecture as Code

Architecture decisions, published as code: written in Markdown, stored in Git, reviewed like any change, and rendered here automatically.

- **[SBAR register](sbar/index.md)**: one-page decision briefs for leaders
- **[Browse by tag](tags.md)**: find artifacts by topic or domain

Each page on this site comes from a Markdown file in the `docs/` folder of the [repository](https://github.com/robertrostsource/archascode). When a file is added or changed on the `main` branch, the site rebuilds within a couple of minutes.

!!! note
    All example content (NovaCorp, CorvusGate, people and figures) is fictitious.
