# Reusable Library

Shared building blocks every agent draws from. Change them through a pull request; every engagement picks up the change on the next build.

- **Domains**: The Agile Security System™ Baseline Perspective domains and relationships
- **Attributes**: SABSA / AEF business attributes, used to form DOMAs
- **Business outcomes**: reusable statements of value, with the 10-K evidence to look for
- **Strategies**: reusable risk mitigation strategies, each abstracted by its business attributes

Source files live in the `library/` folder of the repository.
