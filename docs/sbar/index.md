# SBAR register

One-page decision briefs: Situation, Background, Assessment, Recommendation, and the decision requested.

SBARs in this section appear in the menu automatically, newest file names last. Use [tags](../tags.md) to filter by topic, domain or `adr-recommended`.

## How to add an SBAR

1. Generate it with the Architecture SBAR Agent (Copilot agent, Claude Skill, or Python).
2. Save it as `SBAR-<Topic>-<YYYY-MM-DD>.md`.
3. Drag the file into the `sbar` folder of the repository on GitHub and commit.
4. The site rebuilds in a couple of minutes.

!!! warning "Approval status"
    Publishing an SBAR here does not mean the decision is approved. Check the **Decision Requested** section and the ADR for the outcome.
